## 二、使用方法

1. 打开 https://app.diagrams.net （或 draw.io 桌面版）→ File → Open from → Device → 选择 .drawio 文件；
2. 检查内容与论文底稿一致（不得自行增删技术元素；如需调整仅可移动布局、改配色）；
3. 导出：File → Export as → PNG，勾选 Zoom 200%~300%（保证论文打印清晰），或 SVG（学校模板允许矢量图时优先）；
4. 导出文件命名与论文图号一致（如 图4-1.png），插入论文对应占位块位置，删除占位块；
5. **全部插图完成后**，正文方可将占位说明改为"如图x-x所示"实指句（该差量需报管理方确认后统一执行）。
