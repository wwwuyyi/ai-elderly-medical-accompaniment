# 换电脑部署指南

## 前提：新电脑上需要先装好

| 软件 | 版本 | 下载 |
|------|------|------|
| JDK | 17+ | https://adoptium.net |
| Maven | 3.8+ | `mvn -v` 验证 |
| MySQL | 8.0 | 或直接用项目里的便携版（见下方） |
| Node.js | 18+ | https://nodejs.org （前端/Mock Server需要） |

---

## 快速部署（5步）

### 1. 启动 MySQL
如果新电脑没装MySQL，把项目里的便携版拷过去：

```
D:\MySQL\mysql-8.0.40-winx64\   ← 整个目录打包带走
```

在新电脑上：
```bash
# 初始化数据目录（仅第一次）
D:\MySQL\mysql-8.0.40-winx64\bin\mysqld.exe --initialize-insecure --basedir=D:/MySQL/mysql-8.0.40-winx64 --datadir=D:/MySQL/data

# 启动
D:\MySQL\mysql-8.0.40-winx64\bin\mysqld.exe --defaults-file=D:/MySQL/my.ini

# 新开一个终端，设置密码并建库
D:\MySQL\mysql-8.0.40-winx64\bin\mysql.exe -u root --skip-password -e "ALTER USER 'root'@'localhost' IDENTIFIED BY 'root'; FLUSH PRIVILEGES; CREATE DATABASE escort_db DEFAULT CHARACTER SET utf8mb4;"
```

### 2. 导入数据库表
```bash
D:\MySQL\mysql-8.0.40-winx64\bin\mysql.exe -u root -proot escort_db < sql/01-schema.sql
D:\MySQL\mysql-8.0.40-winx64\bin\mysql.exe -u root -proot escort_db < sql/02-init-data.sql
D:\MySQL\mysql-8.0.40-winx64\bin\mysql.exe -u root -proot escort_db < sql/04-add-chat-tables.sql
```

### 3. 配置 DeepSeek Key（永久）
```cmd
setx AI_API_KEY "sk-你的key"
setx AI_LLM_BASE_URL "https://api.deepseek.com/v1"
```

### 4. 启动 Mock Server（可选，不用DeepSeek时才需要）
```bash
node mock-ai-server/server.js
```

### 5. 启动项目
```bash
# 后端
mvn spring-boot:run

# 前端（新开终端）
cd frontend
npm install   # 仅第一次
npm run dev
```

## 需要改的配置（仅一个文件）

`src/main/resources/application.yml` 第10行，MySQL密码：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/escort_db?...
    username: root
    password: root    ← 改成你新电脑的MySQL密码
```

其余配置全部走环境变量，不用改。

## 不用重装的（打包带着走）

- ✅ `mock-ai-server/` — Node.js零依赖，拷过去直接 `node server.js`
- ✅ `sql/` — 建表SQL脚本
- ✅ `D:/MySQL/` — MySQL便携版整个目录
- ✅ 全部Java源码和前端源码
